### 2. Data Classification Using AI

**Project Type:** Machine Learning / Classification

A machine learning application that classifies Iris flowers using their measurements and a Decision Tree classification model.

**Key Features**
- Uses the Iris dataset.
- Processes four flower measurements as input features.
- Splits data into training and testing sets.
- Trains a Decision Tree classifier.
- Evaluates predictions using accuracy and a confusion matrix.
- Predicts the class of a new flower from user-provided measurements.

**Dataset Overview**
- Total samples: 150
- Input features: 4
- Target classes: 3
- Training samples: 120
- Testing samples: 30

**Model Performance**

| Evaluation Metric | Result |
|---|---:|
| Algorithm | Decision Tree |
| Test Accuracy | 93.33% |
| Correct Predictions | 28/30 |
| Incorrect Predictions | 2/30 |

**Technologies Used**
- Python 3
- NumPy
- Matplotlib
- Scikit-learn

## ⚙️ Getting Started

### Prerequisites

Install Python 3 and Git on your computer.

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/DecodeLabs-AI-Internship.git
cd DecodeLabs-AI-Internship
```

Replace `YOUR-USERNAME` with your GitHub username and update the repository URL if needed.

### Install Dependencies

For projects that require external libraries, navigate to the relevant project folder and run:

```bash
pip install -r requirements.txt
```

### Run a Project

Navigate to the project directory and execute its Python file. For example:

```bash
python main.py
```

On some systems, you may need to use `python3 main.py`.
